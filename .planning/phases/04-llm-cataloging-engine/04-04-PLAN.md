```python
class CatalogingAgent:
    """Orchestrate LLM-powered table cataloging with context accumulation.

    Processes tables in dependency order, maintaining state of cataloged tables
    to provide parent context for dependent table analysis.
    """

    def __init__(self, client: CatalogClient | None = None):
        """Initialize agent with OpenAI client.

        Args:
            client: CatalogClient instance. If None, creates new client.
                    Allows dependency injection for testing.
        """
        self.client = client or CatalogClient()
```

2. **catalog_database method**:
```python
def catalog_database(self, schema_result: SchemaAnalysisResult) -> dict[str, CatalogEntry]:
    """Catalog all tables in dependency order with context accumulation.

    Args:
        schema_result: SchemaAnalysisResult from SchemaIntrospector containing
                      tables metadata and processing_order

    Returns:
        Dictionary mapping table_name to CatalogEntry for all tables

    Raises:
        ValueError: If schema_result has circular dependencies
    """
```

Implementation:
- Check for circular dependencies: `if schema_result.circular_dependencies: raise ValueError(f"Cannot catalog with circular dependencies: {schema_result.circular_dependencies}")`
- Create dict mapping table_name to TableMetadata for fast lookup
- Initialize `state = CatalogState()`
- Iterate over `schema_result.processing_order` (NOT schema_result.tables - order matters):
  - Get TableMetadata for this table from dict
  - Get parent context: `parent_context = state.get_parent_context(table_meta)`
  - Call `self._catalog_table(table_meta, parent_context)` to get CatalogEntry
  - Add to state: `state.add_entry(entry)`
- Return `state.entries`

3. **_catalog_table method (private helper)**:
```python
def _catalog_table(self, table: TableMetadata, parent_context: list[CatalogEntry]) -> CatalogEntry:
    """Catalog single table using LLM with parent context.

    Args:
        table: TableMetadata with columns, PKs, FKs
        parent_context: List of already-cataloged parent tables

    Returns:
        CatalogEntry with LLM-generated description, sensitivity, queries
    """
```

Implementation:
- Build messages list:
  ```python
  messages = [
      {"role": "system", "content": SYSTEM_PROMPT},
      {"role": "user", "content": build_user_prompt(table, parent_context)}
  ]
  ```
- Call LLM with retry: `result = self.client.analyze_table(messages, TableCatalog)`
- Convert TableCatalog to CatalogEntry:
  ```python
  return CatalogEntry(
      table_name=table.table_name,
      description=result.description,
      sensitivity=result.sensitivity,
      example_queries=result.example_queries
  )
  ```

4. **Imports**:
   - From models: TableCatalog, CatalogEntry, CatalogState
   - From client: CatalogClient
   - From prompts: SYSTEM_PROMPT, build_user_prompt
   - From schema: TableMetadata, SchemaAnalysisResult

Add comprehensive docstrings explaining:
- Why dependency order matters (parent context)
- Why circular dependencies must be rejected (can't establish processing order)
- How state accumulation enables context-aware analysis (CATL-05)
