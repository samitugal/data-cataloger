```python
class MySQLExtractor:
    """MySQL/MariaDB schema extractor using INFORMATION_SCHEMA views."""
```

**Method 1: get_tables(connector: DatabaseConnector, schema: str) -> list[str]**
- Query: `SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_SCHEMA = %s AND TABLE_TYPE = 'BASE TABLE' ORDER BY TABLE_NAME`
- MySQL uses uppercase column names in INFORMATION_SCHEMA (TABLE_NAME not table_name)
- Schema parameter is database name (MySQL doesn't use 'public')
- Returns: List of table names

**Method 2: get_columns(connector: DatabaseConnector, table: str, schema: str) -> list[ColumnMetadata]**
- Query: `SELECT COLUMN_NAME, DATA_TYPE, IS_NULLABLE, ORDINAL_POSITION, COLUMN_DEFAULT FROM INFORMATION_SCHEMA.COLUMNS WHERE TABLE_SCHEMA = %s AND TABLE_NAME = %s ORDER BY ORDINAL_POSITION`
- Same nullable conversion as PostgreSQL: `(row[2] == 'YES')`
- Returns: List of ColumnMetadata objects

**Method 3: get_primary_keys(connector: DatabaseConnector, table: str, schema: str) -> list[str]**
- Query: `SELECT COLUMN_NAME FROM INFORMATION_SCHEMA.KEY_COLUMN_USAGE WHERE TABLE_SCHEMA = %s AND TABLE_NAME = %s AND CONSTRAINT_NAME = 'PRIMARY' ORDER BY ORDINAL_POSITION`
- MySQL uses CONSTRAINT_NAME = 'PRIMARY' (not constraint_type='PRIMARY KEY')
- Returns: List of column names

**Method 4: get_foreign_keys(connector: DatabaseConnector, table: str, schema: str) -> list[ForeignKeyMetadata]**
- Query from 03-RESEARCH.md lines 432-458: `SELECT CONSTRAINT_NAME, COLUMN_NAME, REFERENCED_TABLE_NAME, REFERENCED_COLUMN_NAME, ORDINAL_POSITION FROM INFORMATION_SCHEMA.KEY_COLUMN_USAGE WHERE TABLE_SCHEMA = %s AND TABLE_NAME = %s AND REFERENCED_TABLE_NAME IS NOT NULL ORDER BY CONSTRAINT_NAME, ORDINAL_POSITION`
- Critical: `REFERENCED_TABLE_NAME IS NOT NULL` filter distinguishes FKs from PKs/unique constraints
- Returns: List of ForeignKeyMetadata objects

Use same cursor pattern as PostgreSQL. Import models and DatabaseConnector. MySQL column names are UPPERCASE in INFORMATION_SCHEMA queries. Schema parameter is database name (get from connector.config.database).

Note: MySQL INFORMATION_SCHEMA simpler than PostgreSQL (no joins needed for FKs - all in KEY_COLUMN_USAGE).
