**Class structure:**
```python
from graphlib import TopologicalSorter, CycleError
from typing import Optional

class DependencyGraph:
    """Table dependency graph with topological sorting."""

    def __init__(self) -> None:
        self._sorter = TopologicalSorter()
        self._tables_added: set[str] = set()
```

**Method 1: add_table(table: str, dependencies: list[str]) -> None**
- Add table with its FK dependencies to graph
- `self._sorter.add(table, *dependencies)` - unpacks dependency list
- Track tables added in _tables_added set
- Handle self-referencing tables: `sorter.add("categories", "categories")` is valid
- Docstring: "Add table with its foreign key dependencies. Dependencies are tables this table references via FKs."

**Method 2: get_processing_order() -> tuple[list[str], Optional[list[str]]]**
- Returns: (ordered_tables, cycle_nodes)
- If successful: ordered_tables contains topologically sorted table names, cycle_nodes is None
- If cycle detected: ordered_tables is empty list, cycle_nodes contains tables forming cycle
- Use try/except CycleError: `e.args[1]` contains cycle node list
- Use `static_order()` not `prepare()` - static_order returns complete ordered list
- Docstring: "Return table processing order. If cycle detected, returns ([], cycle_nodes)."

Follow exact pattern from 03-RESEARCH.md lines 462-490 (build_dependency_graph function).

Use type annotations. Import TopologicalSorter and CycleError from graphlib. No external dependencies (graphlib is stdlib since Python 3.9).
