**Method: introspect_schema(connector: DatabaseConnector, schema: str | None = None) -> SchemaAnalysisResult**

Algorithm:
1. Route to correct extractor based on connector.config.db_type:
   - 'postgresql' → PostgreSQLExtractor()
   - 'mysql' → MySQLExtractor()
   - else → raise ValueError(f"Unsupported database type: {db_type}")

2. If schema is None, set default:
   - PostgreSQL: schema = 'public'
   - MySQL: schema = connector.config.database

3. Extract tables: `tables = extractor.get_tables(connector, schema)`

4. For each table, build TableMetadata:
   - columns = extractor.get_columns(connector, table, schema)
   - primary_keys = tuple(extractor.get_primary_keys(connector, table, schema))
   - foreign_keys = tuple(extractor.get_foreign_keys(connector, table, schema))
   - Create TableMetadata(schema_name=schema, table_name=table, columns=tuple(columns), primary_keys=primary_keys, foreign_keys=foreign_keys)

5. Build dependency graph:
   - For each TableMetadata, extract unique referenced tables from foreign_keys
   - Call graph.add_table(table.table_name, list(dependencies))
   - Get processing_order, circular_deps = graph.get_processing_order()

6. Return SchemaAnalysisResult(tables=tables_metadata, processing_order=processing_order, circular_dependencies=circular_deps)

Use type annotations. Handle edge cases: empty database (no tables), tables with no constraints, self-referencing FKs.
