  <action>
Create frozen dataclasses for schema metadata following research patterns from 03-RESEARCH.md:

1. **ColumnMetadata** - Immutable column representation:
   - name: str (column name)
   - data_type: str (raw type from information_schema - don't normalize, LLM will interpret)
   - is_nullable: bool (not string 'YES'/'NO')
   - ordinal_position: int (column order in table)
   - column_default: Optional[str] (default value expression)

2. **ForeignKeyMetadata** - Foreign key constraint representation:
   - constraint_name: str (FK constraint name)
   - column_name: str (source column)
   - referenced_table: str (target table name)
   - referenced_column: str (target column name)
   - ordinal_position: int (for composite multi-column FKs)

3. **TableMetadata** - Complete table representation:
   - schema_name: str (PostgreSQL: 'public', MySQL: database name)
   - table_name: str (table name)
   - columns: tuple[ColumnMetadata, ...] (use tuple not list for immutability)
   - primary_keys: tuple[str, ...] (column names in PK, ordered)
   - foreign_keys: tuple[ForeignKeyMetadata, ...] (FK constraints)

Use @dataclass(frozen=True) for immutability. Include comprehensive docstrings. Add type annotations with | for Optional (modern Python 3.10+ syntax per project conventions).

Follow research examples from 03-RESEARCH.md Pattern 1 (lines 77-109).
