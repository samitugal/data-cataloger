- Wrap psycopg.connect() in try-except with specific exception handling

- Catch psycopg.ConnectionTimeout -> TIMEOUT
- Catch psycopg.InterfaceError -> INTERFACE_ERROR
- Return ConnectionTestResult with success=True on successful connection
- Execute "SELECT 1" query to verify connection before returning success
