   ```python
   class CatalogWriter(Protocol):

       def write_relationships(self, table_name: str, foreign_keys: tuple[ForeignKeyMetadata, ...], database_name: str) -> None: ...
   ```

   ```python
       self._writer = writer
   ```

3. Modify catalog_database to call writer after each table is cataloged:
   - After `state.add_entry(entry)`, add writer call block:

     ```python
                 table_name, table_meta.foreign_keys, database_name
             )
         except Exception as e:
             import logging
             logger = logging.getLogger(__name__)
             logger.warning(f"Failed to write {table_name} to storage: {e}")
     ```
