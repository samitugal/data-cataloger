1. Create `src/data_cataloger/storage/writer.py` with class `Neo4jWriter`:

**Constructor:**
- Accept `driver: neo4j.Driver` and `database: str = "neo4j"` parameters
- Store as private attributes `_driver` and `_database`
- Call `driver.verify_connectivity()` in constructor to fail fast (per user decision: health check on startup)

**write_entry method:**
- Signature: `def write_entry(self, entry: CatalogEntry, database_name: str, database_type: str = "postgresql") -> None`
- Uses a SINGLE Cypher query that performs all three MERGEs atomically:
  1. MERGE Database node: `MERGE (db:Database {name: $database_name, type: $database_type})` with ON CREATE SET created_at
  2. MERGE Table node: `MERGE (t:Table {name: $table_name, database: $database_name})` with ON CREATE/ON MATCH setting description, sensitivity, example_queries, timestamps
  3. MERGE HAS_TABLE relationship: `MERGE (db)-[:HAS_TABLE]->(t)`
- Use `driver.execute_query()` with parameterized values (not string concatenation)
- Always specify `database_=self._database` parameter (per research: avoid missing database pitfall)
- Map CatalogEntry fields: table_name, description, sensitivity, example_queries (list[str] stored as Neo4j list property)

**write_relationships method:**
- Signature: `def write_relationships(self, table_name: str, foreign_keys: tuple[ForeignKeyMetadata, ...], database_name: str) -> None`
- For each FK in foreign_keys:
  - Use node-first MERGE pattern (per research: avoid MERGE pattern duplication pitfall):
    ```
    MERGE (source:Table {name: $source_table, database: $database})
    MERGE (target:Table {name: $target_table, database: $database})
    MERGE (source)-[r:REFERENCES_VIA {fk_column: $fk_column, referenced_column: $referenced_column, constraint_name: $constraint_name}]->(target)
    ```
  - This creates stub nodes for uncataloged referenced tables (per user decision)
- Execute one query per FK (simple, correct; batch optimization deferred)

**close method:**
- `def close(self) -> None` that calls `self._driver.close()`

**Context manager support:**
- Implement `__enter__` and `__exit__` for `with` statement support

Import CatalogEntry from `data_cataloger.cataloging.models` and ForeignKeyMetadata from `data_cataloger.schema.models`.

Type annotations: All methods typed, mypy --strict compatible. Use `from __future__ import annotations` if needed for forward refs.
