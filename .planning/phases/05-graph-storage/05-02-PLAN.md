Create `src/data_cataloger/storage/repository.py` with class `GraphRepository`:

**Constructor:**
- Accept `driver: neo4j.Driver` and `database: str = "neo4j"` parameters
- Store as `_driver` and `_database` private attributes

**get_table method:**
- Signature: `def get_table(self, table_name: str, database_name: str) -> CatalogEntry | None`
- Cypher: `MATCH (t:Table {name: $table_name, database: $database_name}) RETURN t.name AS name, t.description AS description, t.sensitivity AS sensitivity, t.example_queries AS example_queries`
- Use `self._driver.execute_query(query, ..., database_=self._database)` (always specify database_)
- Return None if no records found
- Construct CatalogEntry from first record (materialize result immediately, per research pitfall #4)

**list_tables method:**
- Signature: `def list_tables(self, database_name: str) -> list[CatalogEntry]`
- Cypher: MATCH (t:Table {database: $database_name}) WHERE t.description IS NOT NULL RETURN ... ORDER BY t.name
- Filter WHERE t.description IS NOT NULL to exclude stub nodes (stubs have no description)
- Return list[CatalogEntry] materialized from records

**get_relationships method:**
- Signature: `def get_relationships(self, table_name: str, database_name: str) -> list[dict[str, str]]`
- Per user decision: direct relationships only, no multi-hop traversal
- Cypher: MATCH (source:Table {name: $table_name, database: $database_name})-[r:REFERENCES_VIA]->(target:Table) RETURN target.name AS referenced_table, r.fk_column AS fk_column, r.referenced_column AS referenced_column, r.constraint_name AS constraint_name
- Return list of dicts (per user decision: domain objects consistent with codebase)
- Materialize records to list[dict[str, str]] before returning

**get_full_graph method:**
- Signature: `def get_full_graph(self, database_name: str) -> dict[str, list[dict[str, str]]]`
- Returns dict with "nodes" and "edges" keys
- Nodes query: MATCH (t:Table {database: $database_name}) RETURN t.name AS name, t.description AS description, t.sensitivity AS sensitivity
- Edges query: MATCH (source:Table {database: $database_name})-[r:REFERENCES_VIA]->(target:Table) RETURN source.name AS source, target.name AS target, r.fk_column AS fk_column, r.referenced_column AS referenced_column
- Execute as TWO separate queries (simpler, avoids complex Cypher WITH/collect which can have subtle bugs)
- Materialize both to lists

**search_by_sensitivity method:**
- Signature: `def search_by_sensitivity(self, sensitivity: str, database_name: str) -> list[CatalogEntry]`
- Cypher: MATCH (t:Table {database: $database_name}) WHERE t.sensitivity = $sensitivity RETURN ... ORDER BY t.name
- Return list[CatalogEntry]

**search_by_keyword method:**
- Signature: `def search_by_keyword(self, keyword: str, database_name: str) -> list[CatalogEntry]`
- Cypher: MATCH (t:Table {database: $database_name}) WHERE toLower(t.description) CONTAINS toLower($keyword) RETURN ... ORDER BY t.name
- Return list[CatalogEntry]

**Private helper _to_catalog_entry:**
- Extract record-to-CatalogEntry conversion to avoid code duplication across methods
- Handle None values for example_queries (stub nodes may not have this property)

Import CatalogEntry from `data_cataloger.cataloging.models`. Import Driver from `neo4j`.

All methods typed with mypy --strict compliance. Use parameterized queries only (never string concatenation). Always specify database_=self._database in every execute_query call.
